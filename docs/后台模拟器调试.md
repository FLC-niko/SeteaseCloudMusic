# 后台模拟器与 ADB 调试

本项目可以直接通过 Android SDK 的 Emulator、ADB、Gradle 与仓库内置 Python 3 脚本完成构建、启动、姿态切换、截图与矩阵回归，无需打开 Android Studio。

## 一、快速启动与日常操作

脚本 [`scripts/android_emulator.py`](../scripts/android_emulator.py) 仅依赖 Python 3 标准库，自动从 `--sdk`、`ANDROID_HOME`、`ANDROID_SDK_ROOT` 或项目 `local.properties` 解析 SDK 路径：

```bash
# macOS / Linux（Windows 将 python3 替换为 python，按需传 --sdk D:/Android/Sdk）
python3 scripts/android_emulator.py start
python3 scripts/android_emulator.py status
python3 scripts/android_emulator.py install
python3 scripts/android_emulator.py launch
python3 scripts/android_emulator.py capture --output artifacts/emulator/home.png
python3 scripts/android_emulator.py logs
python3 scripts/android_emulator.py ui
python3 scripts/android_emulator.py stop
```

常用参数说明：
- `--serial`：目标设备序列号，默认 `emulator-5556`（放在子命令前，如 `--serial emulator-5554 status`）。
- `start --avd <名称>`：指定 AVD，默认 `Pixel_10_Pro_Fold`。
- `start --gpu <host|software|auto>`：渲染后端，默认 `host`；默认关闭 Vulkan 互操作（`-feature -Vulkan`）以规避反复切换高分辨率面板时的主机 GL 崩溃，确需开启可追加 `--vulkan`。
- `install --apk <路径>`：默认安装 `app/build/outputs/apk/debug/app-debug.apk`。
- `capture --display-id <ID>`：折叠屏默认物理屏可能处于熄灭态，脚本会自动从 `dumpsys display` 选择 `state ON` 的活动物理屏，也可显式指定。

> 更换渲染参数前请先执行 `stop` 确认旧实例退出后再 `start`；若已有同序列号在线实例，`start` 会直接复用而不会更改其启动参数。

## 三、常用 ADB 调试命令

应用发布包名为 `com.setease.cloudmusic`，主入口为 `com.example.seteasecloudmusic.feature.main.MainActivity`。多设备在线时务必带 `-s <serial>`：

```bash
adb -s emulator-5556 devices -l
adb -s emulator-5556 shell am start -W -n com.setease.cloudmusic/com.example.seteasecloudmusic.feature.main.MainActivity
adb -s emulator-5556 shell input tap 200 300
adb -s emulator-5556 shell input swipe 600 1700 600 500 400
adb -s emulator-5556 shell input keyevent KEYCODE_BACK
adb -s emulator-5556 shell uiautomator dump /sdcard/window.xml && adb -s emulator-5556 shell cat /sdcard/window.xml
adb -s emulator-5556 logcat -d -v threadtime
adb -s emulator-5556 logcat -b crash -d
adb -s emulator-5556 shell dumpsys activity exit-info com.setease.cloudmusic
```

> 查询折叠屏物理显示器 ID：`adb -s emulator-5556 shell dumpsys SurfaceFlinger --display-id`。

## 四、折叠姿态、旋转与大字号切换

先确认当前 AVD 支持的设备状态与传感器：

```bash
adb -s emulator-5556 shell cmd device_state print-states
adb -s emulator-5556 emu sensor status
```

以 Pixel Fold 系模拟器为例（`0` 合拢、`1` 半折叠、`2` 展开），需同步切换硬件折叠指令与 `device_state`：

```bash
# 合拢外屏
adb -s emulator-5556 emu fold
adb -s emulator-5556 shell cmd device_state state 0

# 展开内屏
adb -s emulator-5556 emu unfold
adb -s emulator-5556 emu sensor set hinge-angle0 180
adb -s emulator-5556 shell cmd device_state state 2

# 半折叠 + 横屏（观察桌面上下分屏姿态）
adb -s emulator-5556 emu sensor set hinge-angle0 90
adb -s emulator-5556 shell cmd device_state state 1
adb -s emulator-5556 shell cmd window user-rotation lock 1
```

- 切屏后如需唤醒并解无密码锁屏：`shell input keyevent KEYCODE_WAKEUP`、`shell wm dismiss-keyguard`。
- 大字号验证：`shell settings put system font_scale 1.5`（恢复：`1.0`）。
- 窗口缩放验证：`shell wm size 1240x1550`（恢复：`shell wm size reset`）。

## 五、全页面折叠屏矩阵回归

使用 [`scripts/verify_foldable_layouts.py`](../scripts/verify_foldable_layouts.py) 自动完成姿态切换、权限授予、设备测试、截图与哈希校验（结束后自动恢复字号、尺寸、旋转与姿态覆盖）：

```bash
# 全量 9 组窗口配置回归（输出至 artifacts/foldable/verified/）
python3 scripts/verify_foldable_layouts.py

# 仅验证外屏、书本和桌面姿态
python3 scripts/verify_foldable_layouts.py --scenarios outer,book,tabletop

# 断点续跑（仅在源码、脚本与两份 APK 哈希完全一致时复用已通过配置）
python3 scripts/verify_foldable_layouts.py --resume

# 仅复验导航与原生播放器，输出至独立目录
python3 scripts/verify_foldable_layouts.py --pages chrome,native_music --output artifacts/glass/focused

# 指定已有在线模拟器与自定义 adb 路径
python3 scripts/verify_foldable_layouts.py --adb /path/to/adb --serial emulator-5554 --pages native_music --output artifacts/player/focused
```

所有运行产物位于已被 Git 忽略的 `artifacts/` 目录。测试页面使用本地夹具填充歌曲与封面，不发起真实播放或登录；账号相关页面会沿用设备当前登录态，对外分享截图前请注意脱敏。
