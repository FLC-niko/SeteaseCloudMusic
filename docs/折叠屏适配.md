# 折叠屏页面与自适应布局

> 本文档依据当前源码（`core/ui/adaptive/`、`feature/main/AdaptiveNavigation.kt`、`AdaptiveLayoutsTest.kt`）编写，记录现行自适应窗口策略、页面分栏规则与回归测试体系。
>
> 关于 iPhone Duo 交互对齐与播放页/歌单展开细节，请一并参考 [iPhone Duo 官方布局方案对齐](iPhone-Duo官方方案对齐.md)。

## 一、窗口策略（`AdaptiveWindowInfo`）

窗口能力与形态判断集中在 [`core/ui/adaptive/AdaptiveLayout.kt`](../app/src/main/java/com/example/seteasecloudmusic/core/ui/adaptive/AdaptiveLayout.kt) 的 `ProvideAdaptiveWindow` 与 `AdaptiveWindowInfo` 中，基于 Jetpack WindowManager 1.5 的真实窗口指标与 `FoldingFeature`，不依赖设备型号或写死像素分辨率：

- **常规/宽屏宽度断点（`isRegularWidth`）**：`width >= 600.dp`。
- **侧边导航栏条件（`useNavigationRail`）**：`height >= 400.dp && !isTabletop && (width > height || (isFoldable && !isRegularWidth))`。
  - 折叠设备合拢外屏、宽横屏与紧凑横屏使用外缘侧边导航栏（宽屏宽 `84.dp`，紧凑屏宽 `72.dp`）；
  - 展开竖屏、普通手机竖屏及桌面半折叠（`isTabletop`）使用横向底栏。
- **分屏外缘镜像（`sideControlsAtStart`）**：处于多窗口分屏且当前窗口位于屏幕左侧时，侧边操作区自动移至窗口左外缘，远离中线。
- **展开播放器条件（`useExpandedPlayer`）**：`isBook || isTabletop || (isRegularWidth && width > height)`。
- **详情双栏条件（`showDetailAlongside`）**：`hasSelection && ((contentWidth >= 720.dp && contentHeight >= 360.dp) || isBook || isTabletop)`。
- **兼容性兜底**：`WindowInfoTracker`、`supportedPostures` 与 `windowLayoutInfo` 均以 `runCatching` 保护，避免无 WindowManager 扩展的设备（如部分 MIUI 机型）启动异常。

## 二、核心自适应容器

| 组件 | 位置 | 职责 |
|---|---|---|
| `ProvideAdaptiveWindow` / `LocalAdaptiveWindow` | `core/ui/adaptive/AdaptiveLayout.kt` | 采集安全区、窗口尺寸、多窗口位置与分离折痕，向子树广播 `AdaptiveWindowInfo` |
| `AdaptiveContent` | `core/ui/adaptive/AdaptiveLayout.kt` | 居中限制内容最大阅读宽度（默认 `1280.dp`），避免超宽屏内容过度拉伸 |
| `AdaptiveTwoPane` | `core/ui/adaptive/AdaptiveLayout.kt` | 基于窗口真实坐标扣除分离折痕与留白，支持书本（左右）与桌面（上下）双栏拆分，切向不丢失子状态 |
| `AdaptiveModalSheet` / `AdaptiveAlertDialog` | `core/ui/adaptive/AdaptiveModalSheet.kt` | 紧凑屏使用 Miuix `WindowBottomSheet` / `WindowDialog`，宽屏与折痕场景自动限宽、居中并避让折痕 |
| `MusicPane` / `AdaptiveSectionColumn` | `core/ui/adaptive/` | 通用双栏内容窗格与多列内容流排版容器，支持窗口重排时保持阅读锚点 |
| `ExpandedPlaylistBackdrop` | `feature/main/ExpandedPlaylistBackdrop.kt` | 宽屏打开歌单详情时将封面主色（或主题底色）无缝延伸至侧边操作区下方 |

## 三、各页面大屏与折叠姿态表现

| 页面 / 模块 | 宽屏与折叠姿态适配 |
|---|---|
| **主导航、搜索栏与 Mini Player** | 按 `useNavigationRail` 在侧边栏与底栏间切换；短横屏自动将导航入口收进 Miuix `WindowListPopup` 溢出菜单；横向底栏与收缩播放条共用 `HorizontalChromeLayout` 限宽框架（最大 `620.dp`） |
| **首页 / 电台 / 我的** | 未选歌单时展示完整内容流（宽内容区支持多列网格/板块排布）；选中歌单且满足 `showDetailAlongside` 时由详情覆盖内容区并重排封面与曲目双栏，返回后保留原滚动位置 |
| **歌单详情 & 每日推荐详情** | 宽屏/书本姿态左右双栏（左侧封面与播放入口，右侧曲目列表）；桌面姿态上半屏封面、下半屏曲目；窄屏全屏单栏并支持 3 种歌单样式与独立取色记忆 |
| **艺人详情 & 全局专辑浮层** | 封面/简介区与作品/曲目区分栏展示，支持预测性返回手势与跨窗口状态保留 |
| **搜索与建议** | 分类结果自适应多列排布，搜索词、分类标签、匹配歌词展示与列表位置在窗口重排与 Activity 重建后保留 |
| **发现页** | 推荐歌单、榜单、新歌等板块按可用宽度重排（独立页面模块） |
| **全屏原生播放器与歌词** | 展开竖屏保持竖向居中限宽列；宽横屏与书本姿态专辑页双栏、歌词页采用内容双栏 + 底部玻璃控制带；桌面姿态媒体在上、控制与歌词在下；歌词视图状态跨重排保留 |
| **队列、音质、账号、设置与下载目录弹层** | 统一挂载至自适应弹窗/浮层宿主，半折叠时保持在单块可用显示区并支持大字号滚动 |

## 四、自动化验证矩阵

设备回归测试位于 [`AdaptiveLayoutsTest.kt`](../app/src/androidTest/java/com/example/seteasecloudmusic/AdaptiveLayoutsTest.kt)，共包含 **15 项仪器测试**，覆盖全页面渲染截图与核心交互断言：

- 全页面九组窗口矩阵截图（`allPagesRenderAndCapture`）
- 宽屏展开歌单统一取色底座延伸与返回恢复（`expandedPlaylistBackgroundContinuesUnderSideControls`、`expandedPlaylistKeepsSelectionAcrossResizeAndReturnsToFeed`、`playlistStyleSwitchingSurvivesEveryDetailLayout`）
- 顶部栏状态区避让、迷你播放条多宽度与 1.5 倍大字号防遮挡、播放键居中校验
- 侧边玻璃 Dock 拖拽与搜索切换、短屏溢出菜单可达性、分屏左侧镜像定位
- 宽屏重排歌词页状态保留、Activity 重建后导航与搜索保留、折痕双栏边界与滚动锚点校验

通过 `scripts/verify_foldable_layouts.py` 在模拟器上运行 9 组窗口配置（`inner`、`outer`、`landscape`、`outer-landscape`、`book`、`tabletop`、`resized`、`large-font`、`outer-large-font`），操作命令见 [后台模拟器调试](后台模拟器调试.md)。
