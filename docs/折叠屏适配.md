# 折叠屏页面与布局

## 布局原则

按当前窗口的可用宽高和 WindowManager 提供的真实折痕布局，支持内外屏切换、旋转和窗口缩放。保留现有白色内容页、红色强调和玻璃导航风格；大屏通过分栏和内容限宽提高信息密度，封面保持正方形，长标题控制行高，长列表各自滚动。

- 窗口宽度至少 600dp、高度至少 360dp 且没有分隔折痕时使用侧边导航；窄屏使用悬浮底部导航。
- 内容区达到 720dp 宽时，推荐板块可成对排列；详情页在可用高度至少 360dp 时使用介绍与内容双栏。
- 分隔折痕优先于宽度阈值：书本姿态左右分栏，桌面姿态上下分栏。使用组件在窗口中的实际坐标扣除折痕与留白，适用于侧栏、系统边距和嵌套宿主。
- 队列、音质、账号、目录和提示弹层放在同一块可用显示区域内；大屏弹层限宽，内容支持滚动。
- 搜索分类、标签页、播放页显示状态和列表位置随重建保留；推荐流按板块身份重新定位，包含最后操作的右栏。

## 页面清单

| 页面或状态 | 展开大屏与折叠姿态处理 |
| --- | --- |
| 主导航、搜索输入、迷你播放器 | 侧栏/底栏切换；播放条和底栏避开折痕；为内容计算底部留白 |
| 首页 | 每日推荐封面与收藏推荐并排，推荐歌单保留横向浏览，卡片宽度随实际内容区调整 |
| 电台 | 编辑板块双列；打开歌单后显示内容流与详情双栏，窄屏全屏下钻 |
| 我的、创建/收藏/本地音乐 | 资料库与详情双栏，无选择时显示引导占位；保留本地扫描与目录入口 |
| 歌单详情、资料库与电台内嵌详情 | 独立详情为封面介绍与歌曲列表双栏；内嵌详情在已有窗格中展示，避免重复分栏 |
| 每日推荐详情 | 推荐海报与歌曲列表双栏；桌面姿态上下显示，列表独立滚动 |
| 艺人详情 | 简介/封面与歌曲、专辑、MV、歌单、相似艺人等作品板块分栏，标题支持换行 |
| 搜索与建议 | 艺人/专辑/歌单自适应网格；综合结果的封面与歌曲分栏；列表与网格切换保留位置 |
| 发现页 | 推荐歌单、新歌、榜单等板块重排；包括当前未挂载到主导航的独立页面 |
| 原生播放器、歌词 | 大屏同时显示封面与歌词；桌面姿态控制区移入下半屏；控制按钮按实际窗格宽度重排 |
| Web/AMLL 播放器 | 重写 React 布局，原生传递实际 WebView 尺寸与折痕；支持封面/歌词切换、双栏、上下分屏及原有播放桥接 |
| 播放队列、音质选择 | 窄屏底部面板，大屏限宽侧面板；半折叠时置于单块显示区域 |
| 账号入口、验证码、二维码、账号详情、设置 | 限宽表单与面板；半折叠避开折痕；输入法留白和滚动 |
| 播放风格、退出登录、本地目录、网络提示 | 共用适配弹窗宿主，长内容与大字号可滚动 |

## 验证方式

`AdaptiveLayoutsTest` 使用实际 Compose 页面和本地生成的歌曲/封面夹具。每种配置检查 22 个页面或状态，并额外截取搜索分类和播放风格弹层，共 26 张截图。Web 夹具检查真实歌词文字进入 DOM 后再截图，避免只凭 WebView 容器存在判断成功。

设备回归另外检查搜索内容在 Activity 重建后保留、单列转双列的阅读位置、右栏停止滚动后折叠切换的阅读位置，以及横向/纵向模拟折痕两侧的精确边界。它们与页面截图一起在展开内屏运行，共 5 项测试。

使用 Pixel 10 Pro Fold、Android API 37 模拟器，通过独立 Emulator + ADB 后台运行。矩阵包含展开内屏、合拢外屏、内屏横屏、外屏横屏、书本姿态、桌面姿态、1240×1550 窗口、内屏 1.5 倍字号、外屏 1.5 倍字号。每次运行保存窗口与折痕数据、截图、日志及源码/APK 哈希。完整命令见 [后台模拟器调试](后台模拟器调试.md)。这些验证覆盖布局与状态保持；真实硬件的厂商差异需在对应设备验收。

其他检查：Android Debug APK/测试 APK 构建、JVM 单元测试，Web 布局与进度逻辑 4 项测试、Vite 资源构建，以及 `git diff --check`。

2026-11-03 验证结果：九组配置通过，累计 234 张页面截图；内屏 5 项设备回归通过，其他八组各完成全页面渲染。外屏横屏实测约 907×443dp；书本和桌面姿态分别记录到纵向、横向分隔折痕。模拟器图形互操作故障后，对相同源码和 APK 哈希使用 `--resume` 补跑剩余配置；没有复用其他构建的结果。Android 构建、JVM 单元测试、Web 4 项测试和资源构建通过。

实际应用入口另经 ADB 检查：输入 `Luna` 后合拢至 1080×2364 外屏，再展开至 2076×2152 内屏，搜索内容均保留；截图脚本分别选中对应的活动物理显示器。基础设备包名测试通过。

### 既有 Lint 问题

本轮运行 `:app:lintDebug` 得到 48 项 `RestrictedApi` 错误，均位于本轮未修改的 `core/player/MusicService.kt`，涉及 Media3 携带的兼容 API。适配代码曾直接调用 WindowLayoutInfo 受限构造函数，该调用已移除。保留既有错误报告，不通过新增基线或压制规则隐藏。构建与测试可独立运行。

本轮验证结果与构建产物位于本地 `artifacts/foldable/verified/`，不纳入 Git；账号页截图可能包含模拟器已有账号信息。
