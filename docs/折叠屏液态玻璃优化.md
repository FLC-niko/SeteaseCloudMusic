# 折叠屏液态玻璃视觉统一

## 设计目标

展开后继续使用手机端的悬浮胶囊、透镜滑块、连续圆角和弹簧反馈，让窗口尺寸变化只影响内容组织，不切换成另一套视觉系统。玻璃用于导航、播放控制和浮层，正文与封面保持清晰。

## 本次调整

| 区域 | 调整 |
| --- | --- |
| 展开导航 | 三个主入口组成悬浮玻璃 Dock，搜索保留独立透镜按钮；与底栏共用滑块、折射、拖拽和弹簧参数 |
| 搜索 | 使用 54dp 高的玻璃胶囊，统一图标、圆角、高光与阴影 |
| 迷你播放器 | 展开时最大宽度 620dp、高度 60dp，形成独立悬浮层；内容区预留相应空间 |
| 账户与其他浮层 | 统一玻璃材质和连续圆角；账户浮层位于导航、播放条上方，支持返回关闭 |
| 队列、音质、确认框 | 大屏面板限宽并按内容决定高度；半折叠时保持在单块显示区域内 |
| 资料库占位 | 用居中的轻量玻璃引导卡承载信息，背景沿用柔和的冷暖环境光 |
| 原生播放器 | 窄屏与展开版共用封面环境光背景；展开控制区采用深色玻璃托盘，桌面姿态下控制区最大宽度 620dp |
| Web 播放器 | 大屏控制区使用同源的半透明底色、边缘反光和模糊；补充按压反馈并尊重减少动态效果设置 |
| 大字号 | 音质与播放模式按钮保留对称的 72×48dp 空间，避免 Hi-Res 标签换行，并保持播放键居中 |

## 材质与采样

`LiquidGlassPanel` 统一大屏浮层材质：18dp 模糊、8dp 折射高度、18dp 折射量、色散和渐变边缘高光。浅色面板使用 0.64 底色透明度，深色使用 0.78，以保留背景色彩并保障文字对比度。

导航与浮层通过 `LocalGlassBackdrop` 取得背景采样源。背景录制与浮层绘制分开，防止玻璃把自身再次录入纹理。资料库占位区也有独立的环境光采样层。

播放器通过 `LocalPlayerBackdrop` 共用背景：只录制封面环境光，控制区、队列与音质面板都采样这一层。播放页上的玻璃菜单因此反映当前封面颜色。背景沿用手机端的降采样模糊策略，避免重复绘制整屏高分辨率模糊。

## 验证

使用后台模拟器与 ADB，不启动 Android Studio。启动与截图说明见 [后台模拟器调试](后台模拟器调试.md)。

```powershell
$env:GRADLE_USER_HOME='C:/Users/Administrator/.gradle'
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest --console=plain
python scripts/verify_foldable_layouts.py --adb D:/Android/Sdk/platform-tools/adb.exe --output artifacts/glass/final
```

针对导航与播放器调整，可使用定向复验：

```powershell
python scripts/verify_foldable_layouts.py --adb D:/Android/Sdk/platform-tools/adb.exe --pages chrome,native_music --output artifacts/glass/release-review
```

覆盖内外屏、两种横屏、书本/桌面姿态、缩小窗口和内外屏大字号。设备测试包含玻璃 Dock 拖拽与搜索切换、Activity 重建、列表锚点、折痕边界，以及真实账户/播放菜单的打开和关闭。账户浮层还检查底部点击不会穿透到播放列表。

Web 检查在 `amll-web-player` 执行 `npm test` 与 `npm run build`。运行产物保存源码/APK 哈希与页面范围，定向结果不与完整矩阵混用。截图沿用模拟器现有账户，保存在已忽略的 `artifacts/` 下。

本次验证结果：

- 首轮 24 个页面的九组完整矩阵通过；后续细节调整完成后，针对真实导航和播放器再次通过九组定向复验，包含 46 张对应截图。缩小窗口使用紧凑播放器，因此没有大屏队列和音质菜单的两张截图。
- 最终内屏通过七项设备测试；播放键居中检查覆盖 320/350/420dp 宽度与 1.0/1.5 倍字号。
- Debug 应用、设备测试 APK 构建和 JVM 单元测试通过；Web 四项测试与生产构建通过。
- 最终定向报告为 `artifacts/glass/release-review/report.json`，已核对源码与两份 APK 的 SHA256，并确认 APK 内 Web 资源与源码产物一致。
- 对照预览为 `artifacts/glass/preview.jpg`，依次展示外屏、展开导航、展开播放器与账户面板。

矩阵运行期间临时固定旋转策略，结束后恢复原值；恢复前等待原物理面板完成切换。最后追加的面板等待逻辑已通过语法检查，其单独的设备往返复验因自动审批服务超时尚未执行，上述页面与交互验证已完成。
