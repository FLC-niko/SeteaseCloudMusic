# 折叠屏液态玻璃视觉统一

> 本文档依据当前源码（`GlassSurface.kt`、`LiquidGlassPanel.kt`、`AdaptiveNavigation.kt`、`ExpandedPlaylistBackdrop.kt`、`LiquidGlassSettingsSection.kt`）编写，说明宽屏/折叠屏场景下液态玻璃材质、背景采样链路与动态通透度调节机制。
>
> 窗口断点与导航定位规则见 [iPhone Duo 官方布局方案对齐](iPhone-Duo官方方案对齐.md) 与 [折叠屏适配](折叠屏适配.md)。

## 一、视觉统一原则

窗口尺寸和折叠姿态变化只改变信息组织与控件位置，**不切换视觉语言**：手机端与折叠屏/大屏端统一使用悬浮玻璃胶囊、透镜滑块、连续平滑圆角（`RoundedRectangle` / `miuix-squircle`）、重力 3D 棱边高光（`BloomStroke`）与阻尼弹簧反馈，同时全面兼容浅色与深色模式（`AppTheme.colors`）。

| 区域 | 现行视觉实现 |
|---|---|
| **展开与侧边导航** | 首页 / 电台 / 我的三入口组成悬浮玻璃 Dock，搜索保留独立透镜按钮；底栏与侧栏共用 `GlassSegmentedSlider` 透镜折射、3D 水滴着色器、拖拽与弹簧参数 |
| **搜索胶囊** | 统一玻璃材质、连续圆角、高光描边与外阴影，随宽窄屏自适应尺寸 |
| **迷你播放器** | 横向模式与底栏共用最大 `620.dp` 框架并支持滚动紧凑收缩；侧栏模式移入侧边操作区，保留封面、播放/暂停与队列入口 |
| **歌单展开底座** | `ExpandedPlaylistBackdrop` 在宽屏打开歌单时将封面主色延伸至侧边操作区下方（关闭取色背景时恢复 `AppTheme.colors.background`），供侧边玻璃控件连续采样 |
| **浮层与弹窗** | 常规弹窗、设置面板与底部抽屉已迁移至 Miuix `WindowDialog` / `WindowBottomSheet` / `WindowListPopup`；需要透光折射的浮层面板（如音质弹窗、控制托盘、引导卡片）使用 `LiquidGlassPanel` / `GlassSurface` |
| **全屏原生播放器** | 纯原生 Compose 实现（已移除旧 Web 播放器）：封面流体网格背景（`feature/player/presentation/mesh/`）与 `AppleMusicBackground` / `AppleMusicIcons` / `AppleMusicPlaybackControls` 协同，暂停时停止背景动画省电 |
| **大字号适配** | 播放控制与音质/播放模式按钮保留对称触控空间与显式行高，防止 1.5 倍字号下标签换行、裁切或偏心 |

## 二、材质参数与全局通透度调节

所有玻璃控件的参数解析统一收口于 [`core/ui/components/GlassSurface.kt`](../app/src/main/java/com/example/seteasecloudmusic/core/ui/components/GlassSurface.kt)，并响应用户在设置页调整的全局液态玻璃通透度/磨砂等级（`AppTheme.liquidGlass.opacityLevel ∈ [-1f, 1f]`，详见 [`LiquidGlassSettingsSection.kt`](../app/src/main/java/com/example/seteasecloudmusic/feature/auth/presentation/LiquidGlassSettingsSection.kt)）：

1. **通用玻璃容器（`GlassSurface` / `Modifier.liquidGlass`）**
   - 默认光学基线（`GlassDefaults`）：模糊 `1.8.dp`、透镜折射 `24.dp / 24.dp`（通过 `clampLensRefractionHeightPx` 钳制不超过短边 40%，防止窄胶囊产生横向折痕）、铺底透明度 `0.14f`（亮面 `0.20f`）、高频噪点抖动 `0.0045f` 抑制 8-bit 模糊色带、重力联动 3D SDF 棱边高光（`BloomStroke`）。
2. **浮层面板（`LiquidGlassPanel` / `Modifier.liquidGlassPanel`）**
   - 通过 `resolveLiquidGlassPanelParams(isDarkSurface, appearance)` 动态插值：
     - **默认档（`0f`）**：模糊 `6.dp`，折射 `16.dp / 20.dp`，底色透明度浅色 `0.50f` / 深色 `0.66f`；
     - **通透档（`-1f`）**：模糊降至 `1.2.dp`，折射增至 `18.dp / 24.dp`，底色透明度降至浅色 `0.20f` / 深色 `0.30f`；
     - **磨砂档（`+1f`）**：模糊增至 `18.dp`，折射收束至 `12.dp / 12.dp`，底色透明度升至浅色 `0.86f` / 深色 `0.88f`；
   - 当 `backdrop == null` 时自动降级为垂直渐变不透明底板（`0.96f → 0.90f`）并保留 `BloomStroke` 棱边高光。

## 三、背景采样隔离机制

- **主界面采样（`LocalGlassBackdrop`）**：背景内容录制层与悬浮导航/浮层绘制严格分离，避免玻璃把自身再次录入采样纹理；侧边栏背后由 `ExpandedChromeBackground`（或展开歌单时的 `ExpandedPlaylistBackdrop`）提供连续环境光底色。
- **播放器采样（`LocalPlayerBackdrop`）**：仅录制封面动态流体背景层，播放控制托盘、音质液态玻璃弹窗等浮层共享同一采样源，折射结果自然跟随当前专辑主色。
- **性能门控**：全屏播放器覆盖时跳过底层页面及毛玻璃绘制；底栏 3D 水滴着色器在冷启动后分阶段离屏预热，避免首次按压编译着色器掉帧。

