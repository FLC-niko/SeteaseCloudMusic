# SeteaseCloudMusic 开发必看

> 仿 Apple Music 风格 Android 音乐播放器 · 默认内置本地直连网易云引擎，支持切换外部增强 API 代理
>
> 最后更新：2026-11-28

---

## 一、技术栈

| 领域 | 选型 |
|------|------|
| 开发语言 | Kotlin 2.3.20（JDK 21+ 构建，Java 11 字节码目标） |
| UI 框架 | Jetpack Compose（BOM `2026.02.01`）+ **Miuix `0.9.5-rc01`**（`miuix-ui` / `miuix-icons` / `miuix-preference` / `miuix-squircle`，已全面替代 Material3） |
| 架构模式 | 分层架构 + 按功能分包（Feature-based Clean Architecture） |
| 网络请求 | 本地直连网易云加解密引擎 + Retrofit 3.0 + OkHttp + Kotlin Coroutines & Flow |
| 媒体播放 | AndroidX Media3 1.5.1（ExoPlayer + MediaSessionService + 前台服务接管） |
| 图片加载 | Coil Compose 2.7（全局 ImageLoader，200MB 磁盘缓存）+ AndroidX Palette |
| 液态玻璃特效 | Kyant0 `backdrop 2.0.1` + `shapes 1.2.0` + 重力 3D 棱边高光（`BloomStroke`） |
| 歌词管线 | 纯原生 Compose 逐字/逐行渲染（优先并发竞速 AMLL TTML 逐字词库，降级网易云 YRC / LRC + 翻译），支持 SuperLyric 状态栏歌词与蓝牙歌词推送 |
| 下载与本地音频 | AndroidX WorkManager 2.10.1 + `jaudiotagger 3.0.1` + MediaStore/多目录递归扫描 |
| 依赖注入 | **Hilt 2.59.2**（`@HiltAndroidApp` / `@AndroidEntryPoint` + 分模块 Module） |
| 性能与构建 | AGP 9.5.3 / Gradle 9.6.0 / KSP 2.3.6 / `:baselineprofile` + ProfileInstaller 1.4.1 |

## 五、API 与网络引擎备忘

### 双模式网络架构

1. **本地直连引擎（默认启用）**：由 `core/network/local/LocalNeteaseApiInterceptor.kt` 拦截请求，通过 `NeteaseEndpointRegistry`（覆盖 43 路网易云接口）与 `NeteaseCrypto` 在本地加解密后直连上游；二维码登录使用 `LocalQrCodeGenerator`（ZXing Core）离线生成。
2. **外部代理模式（设置可切换）**：关闭本地直连后请求走 `BASE_URL` / `BACKUP_BASE_URL`（在 `app/build.gradle.kts` 配置），由 `ApiEndpointFailoverInterceptor` 自动在主备节点间切换。

### 核心已对接接口清单

| 模块 | 典型端点 | 状态 |
|------|---------|------|
| 搜索与播放 | `/cloudsearch`、`/search/suggest`、`/search/hot`、`/song/detail`、`/song/url/v1`、`/scrobble` | ✅ 已对接 |

### 鉴权机制

1. `AuthCookieStore` 负责 Cookie（核心凭证 `MUSIC_U`）的统一读写与持久化，`CookieSanitizer` 规范化清洗。
2. `AuthInterceptor` 在请求头自动注入 Cookie，并在登录接口未返回 `Set-Cookie` 时从响应 JSON 的 `cookie` 字段兜底提取保存。

## 七、编码规范速查

- **分层规则**：`data` → `domain` → `presentation`，依赖方向单向向内。
- **Feature 内自治**：每个 feature 维护独立的 `data` / `domain` / `presentation` / `di`（Hilt 模块）。
- **core 下沉共享**：网络、播放器、下载、核心模型、缓存、设置、主题与通用组件放 `core/`，不混入具体页面业务。
- **依赖注入**：全局 Retrofit Service 在根 `di/NetworkServiceModule.kt` 提供，具体判断原则见 [HILT_GUIDELINES.md](HILT_GUIDELINES.md)。
- **状态管理**：ViewModel 持有 `MutableStateFlow<UiState>`，Compose 层使用 `collectAsStateWithLifecycle()` 收集；冷启动路径避免在主线程同步读取大缓存或触发并发预热抢占。
- **播放性判断**：优先依据 `privilege` 字段判断能否播放，勿仅按 `fee == 1` 一刀切。
- **UI 规范**：严禁重新引入 Material3 依赖；新增控件优先使用 Miuix 组件与 `AppTheme.colors` 语义色板，确保浅色/深色模式一致可用。
